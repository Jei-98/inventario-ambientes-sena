# Inventario de Ambientes SENA

## Descripción
Aplicación de consola en Java que permite a instructores y coordinadores
del SENA controlar el inventario de cada ambiente y reportar faltantes
o daños, para tomar decisiones de reposición.

## Product Goal
Permitir a los instructores y coordinadores del SENA controlar el
inventario de cada ambiente y reportar faltantes o daños, para tomar
decisiones de reposición.
